# Podcast POC 計畫：台灣口音、磁性男聲、科技味

## 目標
把〈記住了第一招，漏掉了第五招〉（Felix Rieseberg〈How to be more ambitious〉摘譯與導讀，
https://imitator.ai-apps.work/r/fifth-move）做成一集 6–8 分鐘的單人 podcast，
聽眾是工程師與想搞懂 AI 的人。驗證兩件事：
1. **聲音**：能不能做出「台灣口音、低沉有磁性、慵懶隨性、會自嘲」的男主持人，而且整集聲線不漂移。
2. **製程**：從文章到成品 mp3 的自動流程，在 3.8 TTS 已知的長文截斷問題下能不能穩定跑完。

## 風格定位
- 參考「台灣財經閒聊型 podcast」的節奏：單人、像深夜跟朋友聊天、口語、離題一下再拉回來、自嘲、偶爾嘴砲。
- **不模仿、不複製任何真實主持人的聲音**。聲線用文字描述設計（一般特徵：低沉、磁性、慵懶），
  不在 prompt 裡寫任何真人的名字，台詞也不用任何節目的招牌開場或口頭禪。節目與主持人用自創名稱。
- 科技味：
  - 中英夾雜照工程師平常講法（prompt、harness、console error、Claude Code、Three.js），英文詞不翻。
  - 用工程比喻講概念：速度是地基也是天花板、「帳單先付」、裁判的解析度、獨立性與成本。
  - 片頭與片尾用 ffmpeg 合成的短合成器音效（純程式產生，無版權問題）。

## 內容結構（約 2,000 字，6–8 分鐘）
| 段落 | 內容 | 語氣 |
|---|---|---|
| 片頭 cold open | 那則轉傳貼文「別再寫『你是一個資深……』」只是複寫單的第二聯 | 慵懶、帶鉤子 |
| 1 四種野心 | 速度、高度、深度、廣度；速度是地基也是天花板 | 輕鬆解說 |
| 2 高度 | 「讓 app 保持零 crash」背後的基礎建設帳單 | 恍然大悟 |
| 3 深度五招 | 第一招換詞不換法、第五招外部裁判最重要；行星候選 TIC 4206066 的驗證法 | 重點放慢 |
| 4 廣度 | 名詞變動詞、組隊、角色之後要接動作 | 幽默 |
| 5 裁判三件事 | 解析度、獨立性、成本；Three.js 零 console error 但畫面一直閃 | 工程師共鳴 |
| 6 自我效能 | Bandura 四個來源，缺的那格是自己跑一次完整迴圈 | 走心 |
| 片尾 | 三個帶走的重點、日期戳提醒 | 收尾、慵懶 |

## 聲音實驗
### 候選聲線（Gemini 3.8 Flash TTS）
| 代號 | 類型 | 說明 |
|---|---|---|
| D1 磁性深夜 | 語音設計 zh-TW | 三十多歲台灣男生，低沉有磁性、帶一點沙啞、慵懶放鬆，像深夜電台 |
| D2 工程師學長 | 語音設計 zh-TW | 同樣低沉，但更清楚、有科技感、講技術時有自信，偶爾嘴砲 |
| S1 Algieba | studio | Smooth, relaxed, low pitch |
| S2 Charon | studio | Informative, steady, low pitch, 科技解說 |
| S3 Enceladus | studio | Breathy, intimate, low pitch（磁性候選） |
| S4 Umbriel | studio | Laid-back, casual |

### 選聲流程
1. 同一段 試聽稿（約 150 字，含中英夾雜、數字、自嘲語氣）六個聲線各生成一次。
2. Gemini 多模態評審自動打分：台灣口音、磁性、自然度、英文詞發音（粗篩用，不是最終判斷）。
3. 分數最高的聲線生成整集；六段試聽一併給人耳聽，換聲線只要改一個參數重跑。

### ElevenLabs 對照組
- `eleven_v3`，用 Voice Design API 以相同描述生成聲線，再用同一份稿生成。
- 讀 `elevenlabs_key` 環境變數。目前這個 session 讀不到這把 key，要新 session 才會載入；腳本已寫好可直接跑。

## 製程與品質關卡
1. **分段**：每段 250–450 字，依段落切，不切斷句子（pilot 顯示 600 字以上開始不穩、2,000 字會靜默截斷）。
2. **逐段驗證**：音長 ÷ 預期音長（每秒 4.5 字）落在 0.6–1.6 之外就重生成，最多重試 2 次。
3. **一致性**：整集用同一個 `voice_…` ID、同一個基底 style 字串，只在每段加情緒修飾。
4. **數字與專有名詞前處理**：稿子裡直接寫成要念的樣子（百分之零點零五、三點一八天），英文名保持英文。
5. **後製**：段落間插 0.6 秒靜音、片頭片尾音效、ffmpeg `loudnorm` 正規化到 -16 LUFS（podcast 常用標準），輸出 mp3 128 kbps。
6. **成品自檢**：整集再丟給 Gemini 評審聽一次，抓唸錯、截斷、聲線漂移。

## 產出
- `podcast/script/ep01.json`：分段稿（含每段 style）
- `podcast/make_podcast.py`：試聽、選聲、整集生成、後製一條龍
- `podcast/elevenlabs_tts.py`：ElevenLabs 對照組
- `out/podcast/`：試聽 wav、各段 wav、成品 mp3（不進 git）
- `podcast/RESULTS.md`：結果、數據與下一步

## 成本估計
約 8 分鐘音檔 × Flash $9/百萬 audio token × 每秒約 32 token ≈ 每次整集 US$0.14，試聽與重試加起來 < US$1。
